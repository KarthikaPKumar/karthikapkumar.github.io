Synthetic demo

Nexora (DataMedic)

Step through pipeline diagnosis and recovery using recorded synthetic scenarios. The demo explains investigation steps; it does not repair a live data platform.

Recorded scenarios only. No production recovery-time benchmark.

Data flow and architecture

Public repository contains compiled assets and synthetic results, not an operational backend.

  1. Seeded synthetic scenarios
  2. Recorded engine results
  3. Compiled browser demo
  4. Select a failure scenario
  5. Review diagnosis and recovery playback

Why this project

Pipeline failures are easier to discuss when you can step through an example. Nexora, previously DataMedic, makes that investigation visible with synthetic scenarios.

What went wrong

Recorded recovery playback cannot show that an engine will recover from an unseen incident. This public demo has no operational backend or measured production recovery time.

What I’d do differently

I'd connect one real, reproducible test pipeline and measure diagnosis accuracy and failed recoveries before expanding the demo.

Failure and limitations

A recorded recovery cannot demonstrate recovery from unseen incidents. A live diagnostic engine would need separate integration and evaluation.

Scale and evaluation

No measured production latency, throughput or recovery rate is published.

Hosting and cost

Static demo with no database or running backend.

Security and privacy

No company data or credentials are included. Browser selections are temporary.
