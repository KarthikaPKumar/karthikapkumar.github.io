Core team project · Applied data science

VKinder

Help families and practitioners explore how place shapes childhood across Greater Melbourne. A team-built platform connects neighbourhood evidence, family-priority matching and an exploratory school-entry forecast.

346 reporting areas · 8 family priorities · 6.43 percentage-point forecast MAE

Data flow and architecture

Core team project, also named KinderPrint in the repository. Includes data pipelines, an area-matching engine and a web application. The source repository is private.

  1. Public development, environment and service data
  2. Python validation and geographic harmonisation
  3. Family Fit scoring + uncertainty analysis
  4. Ridge school-entry forecast
  5. FastAPI + PostgreSQL
  6. React maps and area comparisons

Failure and limitations

One test transition shares a Melbourne-wide shift. Ridge over-predicts by 3.48 percentage points; nominal 80% intervals cover only 69.9%. Historical origins reuse IRSD 2021, and 2027 interval coverage is not demonstrated. Findings are exploratory, not causal or diagnostic.

Scale and evaluation

The model card reports 346 areas, with all eight needs scored for 330. Chronological evaluation reports ridge MAE of 6.43 percentage points versus 7.56 for persistence on 342 test areas, a 14.9% reduction. These are repository-reported results, not a new independent rerun.

Hosting and cost

The documented deployment uses Vercel for the frontend and AWS Lambda, API Gateway and RDS PostgreSQL for the API and data. No hosting-cost or production-latency benchmark is claimed.

Security and privacy

Area-level indicators do not assess individual children. Missing measures remain missing; data gates reject invalid refreshes and restore prior outputs. The documented API uses a read-only database role.
