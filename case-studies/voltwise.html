Measured prototype

Voltwise

Forecast battery capacity ten discharge cycles ahead from NASA laboratory measurements. Compare held-out predictions against a persistence baseline and inspect the tested analytics pipeline.

0.024 Ah MAE · 560 held-out windows · 44.7% lower error than persistence

Data flow and architecture

Implemented pipeline; the Ollama agent and FastAPI service run locally.

  1. NASA battery files
  2. Python cycle extraction
  3. Leave-one-cell-out evaluation
  4. Random forest forecasts
  5. SQL / dbt / DuckDB metrics
  6. Static dashboard + optional local API

Failure and limitations

Cell-level holdout limits leakage between training and evaluation. Data checks reject invalid forecast populations. Four laboratory cells do not establish vehicle-fleet reliability.

Scale and evaluation

Four cells and 560 held-out forecast windows. No production throughput or latency benchmark is claimed.

Hosting and cost

The public dashboard is static. Running the local model and agent uses your own computer; no hosted LLM service is required.

Security and privacy

The local agent exposes bounded read-only metric tools, not arbitrary SQL, shell access or data writes.
