Open-data prototype

Sensory-Aware Route Planner

Calculate walking routes on a real central-Melbourne street graph. Pedestrian-counter snapshots add context only when freshness and reporting-coverage checks pass.

16,386 graph nodes · 18,772 walking segments · 13,858 addresses

Data flow and architecture

Implemented static demo. Retained AWS backend code is a separate, undeployed path.

  1. OSM + Melbourne open data
  2. Python snapshot extraction
  3. Validate coverage and timestamps
  4. Versioned JSON files
  5. Browser-local Dijkstra routing
  6. Show routes and missing-data states

Failure and limitations

Stale counters are excluded. With no eligible observations, activity-based routing is unavailable while shortest-path routing still works. Noise and lighting remain unknown.

Scale and evaluation

CBD extract: 16,386 connected nodes and 18,772 segments. This is data coverage, not measured user impact or routing latency.

Hosting and cost

GitHub Pages serves static JSON and JavaScript. There is no live database or paid routing API in this demo.

Security and privacy

Address search and route calculation run in the browser. Journeys are not submitted to a remote routing service.
