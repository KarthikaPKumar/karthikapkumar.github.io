2 November 2026

A battery model needs an unfamiliar battery

A model that has seen part of a battery’s history has not really met a new battery. Neighbouring forecast windows overlap, so shuffling rows can put very similar examples on both sides of an evaluation.

Voltwise leaves a whole cell out, then compares its forecasts with persistence: assume the current capacity stays the same. The reported error is lower than that baseline, but the dataset contains only four laboratory cells. That boundary belongs beside the headline result.

The next useful experiment is more batteries and operating conditions, not a more elaborate demo.

2 November 2026

Unknown is a useful routing result

A pedestrian count is not a noise measurement. It is also not a promise about how a street will feel to the person walking along it.

The Melbourne route planner checks observation freshness and reporting coverage. If there is no eligible activity data, shortest-path routing still works, but activity-based routing is unavailable. Noise and light stay unknown.

The interface needs to make that gap obvious. A route line on a map can look more certain than the evidence behind it.

2 November 2026

Lower error does not mean trustworthy intervals

VKinder’s ridge forecast reports 6.43 percentage-point MAE against 7.56 for persistence on one chronological test. That is useful, but it is only part of the story.

The nominal 80% intervals cover 69.9% of test areas. The model also over-predicts by 3.48 percentage points after a Melbourne-wide shift. Areas share that shift, so 342 test areas do not amount to 342 independent tests.

Before trusting the outlook more, the priority is stronger chronological evaluation and past-only inputs. A polished map should not hide an uncertain forecast.
